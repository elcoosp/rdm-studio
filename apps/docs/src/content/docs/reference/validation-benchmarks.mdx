Every release of RDM Studio replays **41 analytical benchmarks**: 30 structural
mechanics cases (`R01–R30`) and 11 Eurocode constants (`E01–E11`). A release ships
only at **41 / 41**. Each benchmark compares the solver output against the exact
analytical solution, not another simulation.

## How to read the certification view

The studio header exposes the 41/41 badge; opening it renders the certification
hierarchy: the executive header with the score, the 4-tier summary strip, a filter
(`Tous (41) | RDM & Flambement (30) | Eurocode 3 (11)`) with search, and the grouped
metrology table with per-benchmark `value / expected / error / tolerance` rows and a
`Copier TSV` export. In French locale every benchmark title is translated; the IDs
stay normative.

## Reproducing a benchmark

Each benchmark is a plain model: the cases above are reproducible in the studio by
drawing the geometry, entering the load and reading the reaction/deflection — the
tolerance shown in the modal is the same `1e-12`-scale bound the Rust test suite uses
(`crates/rdm-solver/tests/validation_40.rs` replays them in CI at every commit).
