is exercised by the benchmark suite (see [validation benchmarks](/reference/validation-benchmarks/)),
and every verification in the app renders these formulas through CalcTrace with the
actual input values.

## SI contract

The engine stores everything in SI units (`m`, `N`, `Pa`, `rad`, `kg/m³`); display
conversions (`mm`, `kN`, `MPa`) happen exclusively in the app layer. The formula
reference above is therefore written in the same SI form the solver uses — no hidden
unit step between a clause and the code that implements it.
