Chaque entrée est exercée par la suite de benchmarks (voir
[benchmarks de validation](/fr/reference/validation-benchmarks/)), et chaque
vérification de l'atelier rend ces formules via CalcTrace avec les valeurs d'entrée
réelles.

## Contrat SI

Le moteur stocke tout en unités SI (`m`, `N`, `Pa`, `rad`, `kg/m³`) ; les conversions
d'affichage (`mm`, `kN`, `MPa`) se font exclusivement dans la couche applicative. La
référence ci-dessus est donc écrite dans la même forme SI que celle du solveur — aucune
étape d'unité cachée entre une clause et le code qui l'implémente.
